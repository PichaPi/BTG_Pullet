ตารางติดตามอายุไก่สาว

วันย้าย · แผนเก็บตัวอย่าง TITER / PCR

งานเก็บตัวอย่าง ค้างเก็บ + 7 วันข้างหน้า · ติ๊กเมื่อเก็บแล้ว

    ฝูงไก่สาว เรียงตามวันย้ายที่ใกล้ที่สุด

    ข้อมูลฝูงไก่สาว อายุปัจจุบัน แผนย้าย / จับ วันเก็บตัวอย่าง (ย้อนจากวันย้าย) ตรวจสอบ
    ฟาร์ม / โรงเรือน Vendor รุ่น จำนวนไก่ วันเริ่มเลี้ยง อายุ (วัน) สัปดาห์-วัน ครบ 105 วัน วันย้าย อายุวันย้าย เหลือ (วัน) สถานะ ก่อนจับ 17 วันTITER + PCR ก่อนจับ 10 วันTITER + PCR ก่อนจับ 3 วันPCR ข้อมูลผิดปกติ

    ไม่พบฝูงตามเงื่อนไขที่เลือก

    วิธีคำนวณ (เหมือนไฟล์ Excel เดิม)
    • อายุ (วัน) = วันที่อ้างอิง − วันเริ่มเลี้ยง · สัปดาห์-วัน เช่น 18-6 = 18 สัปดาห์ 6 วัน (ตัวเลขสีเขียวเมื่ออายุ ≥ 105 วัน)
    • ครบ 105 วัน = วันเริ่มเลี้ยง + 105 วัน · อายุวันย้าย = วันย้าย − วันเริ่มเลี้ยง · เหลืออีก = วันย้าย − วันที่อ้างอิง
    • สถานะ: ไม่มีวันย้าย → รอกำหนดวันย้าย · เลยวันย้าย → ย้ายแล้ว · เหลือ ≤ 7 วัน → ใกล้ย้าย · นอกนั้น → ปกติ
    • แผนเก็บตัวอย่าง ย้อนหลังจากวันย้าย: 17 วัน (TITER + PCR), 10 วัน (TITER + PCR), 3 วัน (PCR) — ติ๊ก ☑ เมื่อเก็บแล้ว สีเทา · ถึงกำหนดภายใน 7 วัน ไฮไลต์เหลือง · เลยวันแต่ยังไม่ติ๊ก ตัวแดง
    • ตรวจสอบ: ยังไม่กรอกวันเริ่มเลี้ยง / วันเริ่มเลี้ยงในอนาคต / ยังไม่กรอกจำนวนไก่ / โรงเรือนซ้ำ / อายุ ≥ 91 วันแต่ยังไม่กำหนดวันย้าย / วันย้ายก่อนวันเริ่มเลี้ยง / ย้ายก่อนครบ 105 วัน / อายุวันย้ายเกิน 125 วัน
