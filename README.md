# BTG Pullet — ตารางติดตามอายุไก่สาว

เว็บแอปแทนไฟล์ `Pullet_Age.xlsx` สำหรับติดตามอายุไก่สาว วันย้าย และแผนเก็บตัวอย่าง TITER / PCR
เพิ่ม / แก้ไข / ลบฝูงได้ในหน้าเว็บ โดยใช้**สูตรคำนวณชุดเดิมจาก Excel ทุกคอลัมน์**

## สิ่งที่ทำได้

- **ตารางฝูงไก่สาว** เรียงตาม**วันย้ายที่ใกล้วันนี้ที่สุดขึ้นก่อน** → ตามด้วยฝูงที่ยังไม่กำหนดวันย้าย → ฝูงที่ย้ายแล้ว
- **สรุปด้านบน**: จำนวนฝูง, ไก่รวม, วันย้ายครั้งถัดไป, ฝูงใกล้ย้าย, งานเก็บตัวอย่าง 7 วัน, ข้อมูลผิดปกติ
- **งานเก็บตัวอย่าง 7 วันข้างหน้า** (แทนแผ่น "แจ้งเข้าเก็บตย.")
- **หน้า Summary** (แท็บด้านบน หรือเปิด `#summary`): ภาพรวมรายกลุ่ม (ฟาร์ม, โรงเรือน, ไก่รวม, อายุเฉลี่ยถ่วงจำนวนไก่, ครบ 105 วัน, รอลงเลี้ยง), การกระจายอายุ, แผนย้ายรายเดือน และอายุปัจจุบัน/วันลงเลี้ยงรายฟาร์ม-โรงเรือน พร้อมแถบอายุเทียบ 105 วันและอายุวันย้าย
- **เพิ่ม / แก้ไข / ลบ** ผ่านฟอร์ม พร้อมดูผลคำนวณทันทีระหว่างกรอก
- กรองตามกลุ่ม (KBP / ไก่สาวโครงการ / กลุ่มใหม่), ค้นหา, ซ่อนฝูงที่ย้ายแล้ว, ดูเฉพาะข้อมูลผิดปกติ
- เปลี่ยน**วันที่อ้างอิง**ได้ (ค่าเริ่มต้น = วันนี้ เหมือน `=TODAY()`)
- **ส่งออก Excel** ที่มีสูตรเดิมอยู่ในเซลล์ (เปิดใน Excel แล้วคำนวณต่อได้) และส่งออก/นำเข้า JSON
- ใช้ได้ทั้งคอมพิวเตอร์และมือถือ (มือถือแสดงเป็นการ์ด)

## วิธีคำนวณ (ยกจาก Excel 1:1)

| คอลัมน์ | สูตร |
|---|---|
| อายุ (วัน) | วันที่อ้างอิง − วันเริ่มเลี้ยง |
| อายุ (สัปดาห์-วัน) | `INT(อายุ/7) & "-" & MOD(อายุ,7)` |
| ครบ 105 วัน | วันเริ่มเลี้ยง + 105 |
| อายุวันย้าย | วันย้าย − วันเริ่มเลี้ยง |
| เหลืออีก (วัน) | วันย้าย − วันที่อ้างอิง |
| สถานะ | ไม่มีวันย้าย → รอกำหนดวันย้าย · เลยวันย้าย → ย้ายแล้ว · เหลือ ≤ 7 วัน → ใกล้ย้าย · นอกนั้น → ปกติ |
| ก่อนจับ 17 / 10 / 3 วัน | อายุ = อายุวันย้าย − n · วันที่เก็บ = วันย้าย − n (17, 10 = TITER + PCR · 3 = PCR) |
| ข้อมูลผิดปกติ | ลำดับเงื่อนไขเดียวกับคอลัมน์ "ตรวจสอบ" ของแผ่น ไก่สาวโครงการ |

วันเก็บตัวอย่างมี **checkbox** — ติ๊กเมื่อเก็บแล้ว = สีเทา · ถึงกำหนดภายใน 7 วัน = ไฮไลต์เหลือง · เลยวันแต่ยังไม่ติ๊ก = ตัวแดง (ขึ้นในกล่อง "งานเก็บตัวอย่าง" จนกว่าจะติ๊ก) · อายุ ≥ 105 วัน = ตัวเลขเขียว
สูตรทั้งหมดอยู่ใน [`js/calc.js`](js/calc.js) และมีชุดทดสอบเทียบกับค่าที่ Excel คำนวณไว้ใน [`tests/calc.test.js`](tests/calc.test.js)

> หมายเหตุ: ในไฟล์ Excel เดิม คอลัมน์ "สถานะ" มีเฉพาะแผ่น KBP และ "ข้อมูลผิดปกติ" มีเฉพาะแผ่น ไก่สาวโครงการ — ในเว็บแอปแสดงทั้งสองคอลัมน์ให้ทุกกลุ่ม (สูตรเดิม)

## ข้อมูลเก็บที่ไหน

ข้อมูลอยู่ในไฟล์ [`data/flocks.json`](data/flocks.json) ของ repo นี้ การบันทึกมี 3 แบบ (แอปเลือกให้อัตโนมัติ):

1. **บันทึกขึ้น GitHub** (แนะนำเมื่อเปิดผ่าน GitHub Pages) — เมนู *เพิ่มเติม → ตั้งค่าบันทึกขึ้น GitHub*
   ใส่ [Fine-grained token](https://github.com/settings/personal-access-tokens/new) ที่ให้สิทธิ์ **Contents: Read and write** เฉพาะ repo นี้
   ทุกครั้งที่เพิ่ม/แก้ไข/ลบ แอปจะ commit `data/flocks.json` ให้อัตโนมัติ (ย้อนดูประวัติการแก้ไขได้จาก commit history)
   Token เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น
2. **บันทึกในเครื่องนี้** — ถ้ายังไม่ตั้งค่า GitHub การแก้ไขจะเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น (คนอื่นไม่เห็น)
3. **ข้อมูลออนไลน์** — เมื่อเปิดเป็น Artifact บน claude.ai (ไฟล์ `dist/pullet-age-tracker.html`) ข้อมูลเก็บในฐานข้อมูลของ Artifact และอัปเดตสดให้ทุกคนที่เปิด

## เปิดใช้งานเป็นเว็บ (GitHub Pages)

1. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
2. รอ 1–2 นาที แล้วเปิด `https://pichapi.github.io/BTG_Pullet/`

> GitHub Pages ของ **private repo** ใช้ได้เฉพาะบัญชีแบบเสียเงิน (Pro / Team) — ถ้าเป็นบัญชีฟรีต้องเปลี่ยน repo เป็น public ก่อน (ข้อมูลใน `data/flocks.json` จะเปิดให้ทุกคนเห็น)

ทดสอบในเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000
